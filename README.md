# Joldosh — сайт турагентства

**Демо:** https://joldosh-travel.vercel.app

Двуязычный (RU/EN) сайт вымышленного турагентства из Бишкека: каталог туров, страница тура, заявка на бронирование и админка. Демо-проект для портфолио.

> _Joldosh_ по-кыргызски — «попутчик».

## Стек

- **Next.js 16** (App Router, Server Components, Turbopack), **React 19**, **TypeScript**
- **Tailwind CSS 4** + **shadcn/ui** (Radix UI)
- **next-intl** — языки через сегмент `[locale]` и `next/root-params`
- **zod** — схема данных туров, проверка параметров из адреса и форм
- **Resend** + **React Email** — письма с заявками
- ESLint, Prettier, GitHub Actions (lint, типы, формат, сборка)

## Запуск

Нужен Node.js 20.9+.

```bash
npm install
cp .env.example .env.local   # контакты и ключ Resend для заявок
npm run dev                  # http://localhost:3000
```

| Команда             | Что делает                             |
| ------------------- | -------------------------------------- |
| `npm run dev`       | Сервер разработки                      |
| `npm run build`     | Продакшен-сборка                       |
| `npm run lint`      | ESLint                                 |
| `npm run typecheck` | Генерация типов маршрутов + `tsc`      |
| `npm run format`    | Prettier (сортирует и Tailwind-классы) |

## Структура

```
messages/              тексты интерфейса: ru.json, en.json
src/
  app/[locale]/        страницы: главная, tours/, tours/[slug]/, destinations/,
                       about/, contacts/
  components/          layout/, home/, tours/, destinations/, booking/, ui/ (shadcn)
  config/site.ts       контакты и меню
  data/                демо-данные: 11 туров и 8 направлений на двух языках
  i18n/                настройки next-intl: языки, навигация, форматы цен и дат
  lib/booking/
    schema.ts          zod-схема заявки
    actions.ts         Server Action: проверка, защита от спама, отправка
    email.tsx          шаблон письма менеджеру (React Email)
  lib/tours/
    schema.ts          zod-схема тура — из неё же выводятся типы
    filters.ts         фильтры каталога: разбор адреса, фильтрация, сортировка
    queries.ts         единственная точка доступа к данным (server-only)
  proxy.ts             определяет язык и перенаправляет / → /ru или /en
```

## Решения

- **Язык — часть адреса** (`/ru/...`, `/en/...`): у каждой версии своя ссылка, её индексируют поисковики. При первом заходе на `/` язык выбирается по настройкам браузера.
- **Язык читается через `next/root-params`** (Next.js 16.3): не нужно пробрасывать `locale` через пропсы или вызывать `setRequestLocale` в каждой странице, при этом страницы остаются статическими.
- **Тексты типизированы**: опечатка в ключе `t("...")` — ошибка TypeScript.
- **Контент туров тоже двуязычный**: поля вида `{ ru, en }` в данных, а не только переводы интерфейса.
- **Данные проверяются схемой zod** при сборке: опечатка в туре — ошибка сразу, а не пустое место на странице. Та же схема пригодится для форм админки.
- **Слой данных отделён от страниц**: всё идёт через `lib/tours/queries.ts` с асинхронными функциями. Когда появится база, поменяется один файл.
- **Фильтры каталога — в адресе** (`/tours?destination=turkey&budget=1000`): ссылкой можно поделиться, страница рендерится на сервере. Некорректные параметры (`?budget=abc`) не ломают страницу — zod их отбрасывает.
- **Отзывчивые фильтры**: переход идёт в `useTransition`, а выбранное значение показывается сразу через `useOptimistic`, не дожидаясь ответа сервера.
- **Страницы туров собираются заранее** (`generateStaticParams`) — 11 туров × 2 языка.
- **Заявки — через Server Action**, без отдельного API. Форма работает и без JavaScript, а с ним показывает ошибки у полей и не теряет введённое. Server Action — публичный POST-эндпоинт, поэтому всё проверяется на сервере: данные тура и дата берутся из каталога, а не из формы, так что подменить их нельзя. От CSRF защищает сам Next.js (сверяет заголовки Origin и Host).
- **Защита от спама без капчи**: скрытое поле-ловушка и минимальное время заполнения. Боту отвечаем «успех», но письмо не отправляем.
- **Письмо всегда на русском** — рабочем языке агентства, а язык сайта указан в письме, чтобы менеджер ответил туристу на его языке. Номера вида `0700 123 456` приводятся к `+996…` для ссылок `tel:` и WhatsApp.
- **Цвета — токены в `globals.css`**; фирменный оранжевый подобран так, чтобы белый текст на кнопках проходил WCAG AA (контраст 4.7:1).
